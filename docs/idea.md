解决大学生/研究生在科研起步阶段“找文献难、处理数据繁、实验设计盲、写作规范弱”的核心痛点

项目定位与核心愿景 定位：面向高校学生的“AI科研合伙人”，覆盖从“文献调研 -> 知识构建 -> 数据挖掘与绘图 -> 实验设计 -> 论文撰写与规范审查”的科研全生命周期。



多智能体系统架构（Multi-Agent Architecture） 系统采用 Orchestrator（主控调度）+ Sub-agents（领域专家） 的架构。底层基于 LangGraph 或 CrewAI 实现有状态的工作流。 

1. 🕵️‍♂️ Retriever & Parser Agent（文献侦察与解析员） · 核心职责： · 工具配置：Arxiv API、Semantic Scholar API、**CNKI/万方（视版权接入方式）、Google Scholar 镜像**PyPDF2/Grobid（PDF解析）、向量数据库（Milvus/Chroma）。 · 工作逻辑：接收用户研究方向（如“大模型在医疗诊断中的应用”），自动检索近5年高引论文。利用长文本大模型提取：研究问题、核心方法、数据集、实验结果、局限性。输出结构化摘要。语义检索 + 结构化精读 + 文献矩阵自动生成。
   
   - **结构化精读**：对每篇文献输出固定 Schema 笔记——研究问题 / 方法 / 数据 / 核心结论 / 局限 / 与本课题相关性（六级评分）。
   - **文献矩阵（Literature Matrix）**：N 篇文献 × M 个维度的对比表格，支持导出 Excel。

2. 🧠 Knowledge Graph Agent（领域知识构建者） · 核心职责：跨文献知识融合，构建垂直领域知识图谱，发现研究空白（Research Gap）。 · 工具配置：Neo4j（图数据库）、NER（命名实体识别）模型、关系抽取模型。 · 工作逻辑：将上一阶段解析的碎片化知识（方法、数据集、指标）存入图数据库。通过图谱分析，自动向用户指出：“目前大多数研究集中在A方法，但B数据集上的表现普遍较差，这是一个潜在的研究切入点。”

3. 📊 Data Analyst Agent（数据挖掘与实验员） · 核心职责：自动化数据处理、特征工程、模型训练与可视化。 · 工具配置：安全沙箱环境（E2B或Docker）、Python解释器、Pandas/Scikit-learn/Matplotlib库。 · 工作逻辑：用户上传实验数据（CSV/Excel）。Agent根据用户意图，自动编写Python代码进行数据清洗、异常值处理、相关性分析，并绘制统计图表。支持“代码执行-报错-自动Debug-重新执行”的闭环。

**上传 CSV/Excel 实验数据 → 自动识别数据类型 → RAG 召回对应绘图模板、统计方法、期刊规范 → Agent 生成 Python 绘图代码 → 隔离沙箱安全执行 → 输出高清图、标注异常点、生成可解释分析报告，附带可复现代码。RAG 检索专业知识库：绘图模板、拟合算法、期刊绘图规范、材料 / 地学教材依据****出版级可视化**：默认遵循学术图表规范（分辨率、字体、误差线、配色无障碍友好），可一键导出矢量图。

4.🧪 Experiment Designer Agent（实验方案优化师） · 核心职责：基于文献和现有数据，推荐或优化实验方案。 · 工具配置：大模型推理引擎、超参数优化算法（如Optuna）、领域知识库。 · 工作逻辑：结合Knowledge Graph中的SOTA（State of the Art）方法，对比用户当前的实验设置，提出改进建议（如：“建议将学习率从0.01调整为0.001，并引入Attention机制，参考XX论文”）。

5.📝 Academic Reviewer Agent（学术规范审查官） · 核心职责：学术写作辅助、引用规范、查重与格式审查。 · 工具配置：Zotero/EndNote API、学术查重接口（模拟）、LaTeX/Word格式模板引擎。 · 工作逻辑：在用户撰写论文阶段，实时检查引用格式（APA/MLA/IEEE），自动生成BibTeX。对语句进行学术化润色，并检查是否存在学术不端风险（如过度引用、洗稿）。

三、 核心工作流（User Journey） 

1. 启动阶段：用户在界面输入“我想研究基于RAG的垂直领域问答系统”。
   
   2. 文献调研：Retriever Agent 在3分钟内解析30篇核心论文，Knowledge Graph Agent 生成一张“技术演进路线图”和“研究空白分析报告”。 

2. 数据实验：用户上传一份问答对数据集。Data Analyst Agent 自动编写代码进行数据清洗，并搭建一个Baseline模型，输出初步的准确率图表。

3. 方案优化：Experiment Designer Agent 根据文献指出，当前Baseline缺少“重排序（Rerank）”模块，建议加入并自动生成修改后的代码框架。

4. 论文撰写：用户开始撰写论文，Reviewer Agent 自动插入参考文献，并提示“第3段引用格式错误，建议修改为IEEE格式”。

**竞赛创新亮点（评委加分项）**

1. 从“被动问答”到“主动科研规划”：系统不仅回答问题，还会主动指出文献中的矛盾点，提出实验假设。
2. 代码沙箱与自动Debug：真正实现了“数据挖掘分析”的落地，而不是仅仅给出代码片段。Agent能自己运行代码、看报错、改代码。 

3. 知识图谱+RAG双引擎：传统RAG容易产生幻觉，本方案通过构建Neo4j知识图谱，确保科研事实的准确性和可追溯性。
4. 全周期闭环：市面上多为单一功能（如仅做文献总结）的工具，本方案打通了“找->读->算->写”的完整链路。
