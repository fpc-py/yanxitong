# 实验设计库（超参先验 / 消融模板 / 统计功效 / 回滚判据 / 资源估算）

本库为实验方案优化引擎提供"经验先验"证据：超参搜索区间、消融与对照模板、
统计功效要求、资源估算经验值与失败回滚判据。所有区间是**常见文献的起点区间**，
必须结合具体任务与数据集规模调整，不可当作硬性结论引用。

## 超参先验区间（学习率）

- CNN（ResNet/VGG 系）：SGD+动量 0.05–0.1，Adam/AdamW 1e-4–1e-3；批大小越大，
  学习率上限越高（线性缩放规则 lr ∝ batch/256 作为起点）。
- ViT/Transformer 系：AdamW 1e-5–1e-3（微调下更常用 2e-5–5e-5），权重衰减
  0.01–0.1；ViT 比 CNN 更依赖 warmup（5%–10% 总步数）。
- LSTM/RNN：Adam 1e-4–1e-2，裁剪梯度范数 1.0–5.0 防梯度爆炸。
- 快速探针：以先验区间中值为起点跑 1–2 epoch，损失不下降则将 lr 乘 0.1 重试，
  震荡甚至发散则乘 0.3 并加 warmup。

## 超参先验区间（批大小与优化器）

- 批大小：GPU 显存允许下优先 32–256；过小（<16）批归一化统计不稳定，
  过大（>512）常需配套提高学习率并延长训练轮数。
- 优化器选择：CNN 分类默认 SGD+Momentum 0.9（泛化常更好）；Transformer 默认
  AdamW；小数据集/快速验证用 Adam/AdamW 更稳。
- 调度器：余弦退火（CosineAnnealingLR）作为通用默认；短训练（<30 epoch）用
  OneCycle；检测/分割等长训练常用 StepLR 或 ReduceLROnPlateau（patience 5–10）。
- 混合精度：fp16/bf16 通常提速 1.5–2×，精度损失 <0.5% 时可接受作为默认项。

## 正则化与数据增强先验

- Dropout：全连接层 0.3–0.5，Transformer 注意力/隐藏层 0.0–0.1；过大会欠拟合。
- 权重衰减：SGD 1e-4–1e-2 常用 5e-4；AdamW 0.01–0.1 常用 0.05。
- 图像增强基线：随机裁剪 + 水平翻转（注意任务是否具有方向语义）；进阶：
  RandAugment（N=2, M=9）、Mixup（α=0.2）、CutMix（α=1.0）——小数据集优先。
- 文本：同义词替换/回译/EDA；表格：SMOTE 仅用于类不均衡且须在训练折内做，
  禁止先过采样再划分（数据泄漏）。
- 标签平滑 0.1 常用于分类并缓解过自信；与蒸馏/对抗训练组合时需单独消融。

## 消融实验模板

- 目的：量化每个组件的独立贡献，而不是只报告完整模型的最终指标。
- 模板：①完整模型（Full）②移除组件 A ③移除组件 B ④仅基线（Base）
  ⑤可选：组件 A 单独加到基线上（add-on）。每次只变一个因素。
- 每格配置记录：随机种子固定 ≥3 个（如 42/43/44），报告均值±标准差；
  单次运行结果不得作为消融结论。
- 报告格式：`移除 A 后准确率 91.2%→88.5%（Δ=−2.7，n=3，p=0.02）`；
  Δ 小于随机种子波动（σ）时判为"无显著贡献"。
- 采样策略消融：数据增强/重采样类组件需额外报告"无增强基线"，防止把
  训练轮数增加带来的收益误归因给增强策略。

## 对照实验与重复

- 必须包含：与当前 SOTA/最强基线的同数据同划分对照；与用户现有配置的对照。
- 划分一致：固定 train/val/test 划分文件（或用同一随机种子），否则对比无效。
- 重复：主结果 ≥3 个种子；关键结论 ≥5 个种子；报告均值±SD 与配对检验结果。
- 防止测试集调参：所有超参选择只在验证集上做，测试集仅用于最终报告一次。

## 统计功效与样本量

- 两独立均值比较所需每组的近似样本量：
  n ≈ 16 / (Δ/σ)²（Δ 为目标可检测差异，σ 为噪声标准差，α=0.05, power=0.8）。
  例：想检测 0.5σ 的差异需每组 ≥64 个样本/种子组合。
- 实验点数不足时：增加种子数（方差来自种子时最有效）或改用配对设计
  （同一划分下的两个模型对比天然配对，检验用配对 t/Wilcoxon）。
- 报告要求：预先声明最小有意义差异（MMD）与目标功效；事后补算功效只能作为
  解释，不能作为显著性依据。
- 多组对比必须做多重比较校正（Bonferroni/FDR），否则假阳性随组数膨胀。

## 失败回滚判据

- 训练不收敛：连续 3 个 epoch 验证损失不下降且高于基线 10% → 回滚到上一个
  可用配置，lr×0.1 或加 warmup 后重试一次。
- 过拟合警戒：验证损失连续 5 个 epoch 上升且训练-验证间隙 >20% → 启用早停
  （patience 10）并加正则/增强，禁用"继续堆轮数"。
- 资源超限：单次运行超预算 50%（时长或显存）→ 立即回滚并降批大小/分辨率，
  不允许"赌最后一轮能收敛"。
- 结果异常：指标优于基线 ≥2σ 且无机制解释 → 首先核查数据泄漏/划分错误，
  回滚该次运行，禁止直接上报。

## 资源估算经验值

- 训练时长粗估：时长 ≈ 单 epoch 时间 × 期望轮数 × (1 + 调参试错 2–3×)。
  单 epoch 时间 = 样本数 / 吞吐；图像分类吞吐（单卡 V100/A100 级）：
  224px ResNet-50 约 800–1500 img/s、ViT-B/16 约 200–400 img/s。
- 显存粗估：参数显存 ≈ 参数量 × 4B（fp32）/ 2B（fp16）；训练总显存 ≈
  参数显存 × 3–4（梯度+优化器状态+CUDA 上下文）＋激活值（批大小线性相关）。
- CPU 侧：数据加载用 num_workers=4–8、pin_memory 开启；数据预处理成为瓶颈时
  先将增强放到 GPU（如 torchvision v2）。
- 预算编排：搜索阶段（小分辨率/子集）→ 确认候选 → 全量训练；搜索预算
  不超过总预算的 30%。

## 可复现性清单

- 固定随机性：Python/NumPy/PyTorch 种子；DataLoader worker 种子；cudnn
  deterministic=True（速度损失约 10%–20%，需权衡）。
- 记录：代码 commit、数据版本指纹（哈希）、完整配置 JSON、环境锁
  （pip freeze / conda export）、硬件型号与驱动版本。
- 输出：训练日志 + 每种子指标 + 最优权重哈希；报告附"复现命令"一节。
- 判定标准：同环境同配置重跑指标差异应 <0.5%；超过则排查非确定性算子
  （如 scatter_add、原子加）并记录在复现说明中。
