# 统计方法库（方法选择 / 前提假设 / 报告格式）

本库用于数据分析的统计方法选择。核心原则：**先检查前提假设，再选择方法**；
每步检验都必须报告检验名、统计量、p 值、样本量；所有 p 值保留合适精度并注明
是否经过多重比较校正。

## 描述统计与分布检验

- 连续变量：报告 n、均值±标准差（正态）或 中位数[IQR]（偏态）；百分位用
  P25/P50/P75。偏度绝对值 >1 或均值-中位数差异 >0.2×SD 提示明显偏态。
- 正态性检验：Shapiro-Wilk（n<50 首选，`scipy.stats.shapiro`），
  Kolmogorov-Smirnov（n≥50）。p>0.05 不能证明正态，只说明未检出偏离；
  样本量 >300 时该检验过度敏感，应结合直方图/QQ 图目视判断。
- 报告格式：`Shapiro-Wilk W=0.94, p=0.11，数据未显著偏离正态（n=42）`。

## 独立样本 t 检验（两组比较）

- 适用：两组独立样本均值比较。前提：①近似正态 ②方差齐性
  （`scipy.stats.levene`，p>0.05 认为齐）。
- 代码：`scipy.stats.ttest_ind(a, b, equal_var=True/False)`；方差不齐用
  Welch 校正（`equal_var=False`）。
- 不满足正态 → 改用 Mann-Whitney U（`scipy.stats.mannwhitneyu`），报告
  U、p、秩均值。
- 报告格式：`处理组显著高于对照组（t(38)=2.71, p=0.010, Cohen's d=0.86）`。
- 常见错误：把重复测量当独立样本（应使用配对检验）；只报 p 不报效应量。

## 配对 t 检验 / Wilcoxon 符号秩

- 适用：同一对象前后测量、配对设计。
- `scipy.stats.ttest_rel`；差值不正态 → `scipy.stats.wilcoxon`。
- 报告差值均值±SD 与 95% 置信区间；若差值 CI 不含 0 则与 p<0.05 一致。

## 单因素方差分析（ANOVA，≥3 组）

- 前提：①各组近似正态 ②方差齐性（Levene p>0.05）③观测独立。
- `scipy.stats.f_oneway(g1, g2, g3)`；显著后必须做事后两两比较
  （Tukey HSD 或 Bonferroni 校正），不能直接用多轮 t 检验。
- 方差不齐 → Welch ANOVA；-非正态 → Kruskal-Wallis
  （`scipy.stats.kruskal`）+ Dunn 事后检验。
- 报告格式：`F(2, 57)=4.82, p=0.012, η²=0.14；Tukey 校正后 A 组显著高于
  C 组（p_adj=0.009）`。

## 卡方检验（分类变量关联）

- 前提：期望频数 ≥5 的单元格占比 >80%；2×2 表优先报告 Yates 校正
  （`chi2_contingency(..., correction=True)`）；总样本 <40 用 Fisher 精确检验。
- 报告：`χ²(1, n=120)=6.12, p=0.013, Cramér's V=0.23`。
- 注意区分卡方（关联）与比例 Z 检验（两组比例差）。

## 相关分析

- 双变量都近似正态 → Pearson r；存在明显偏态/序数 → Spearman ρ。
- 必须报告散点图目视检查（线性、异常值）；|r|>0.8 需要警惕共线性。
- 相关系数置信区间建议用 Fisher z 变换；样本量 <30 时相关系数波动很大，
  报告需谨慎。
- 报告格式：`Pearson r=0.78, p<0.001, n=45（95% CI: 0.62-0.88）`。
- 常见错误：从相关性直接推断因果；对明显非线性关系硬套 Pearson。

## 线性回归

- 五前提：线性、残差独立、残差正态、同方差、自变量无严重共线性
  （VIF<5，>10 严重）。
- `scipy.stats.linregress` 或 `sklearn.linear_model.LinearRegression`；
  报告 R²、调整后 R²、每个系数及其 p 值、残差诊断图。
- 多元回归报告格式：
  `y = 12.3 + 2.4x₁ − 0.8x₂；R²=0.71, F(2,42)=51.2, p<0.001；
  x₁: β=2.40, p<0.001；x₂: β=−0.80, p=0.042`。
- 异方差 → 稳健标准误；明显非线性 → 多项式项或变换（log/sqrt）。

## 多重比较校正

- 比较次数 k>1 时必须校正：Bonferroni（p_adj = p×k，保守）或
  Benjamini-Hochberg FDR（探索性研究更常用，控制错误发现率）。
- 报告写明校正方法与校正后的 p 值（p_adj）；不要混用校正与未校正结果下结论。

## 效应量与置信区间

- 均值差：Cohen's d（0.2 小 / 0.5 中 / 0.8 大）。
- 方差解释：η²（ANOVA）、R²（回归）。
- 相关系数本身即效应量。
- 所有主要结论都应给出 95% CI；CI 比 p 值携带更多信息，期刊普遍要求。
- 报告格式：`Cohen's d=0.86 (95% CI: 0.21-1.48)，中等偏大效应`。

## 异常值识别与处理

- 规则：IQR 法（<P25−1.5×IQR 或 >P75+1.5×IQR）标记可疑值；
  3σ 法仅适用于近似正态数据。
- 处理顺序：先核对数据录入 → 判断是技术异常还是真实生物学/实验变异 →
  仅技术异常可剔除（并在文中说明剔除数量与理由）→ 保留时用稳健统计
  （中位数、Winsorize、稳健回归）并敏感性分析。
- 禁止：不说明就剔除；用剔除异常值来制造显著性。

## 常见统计误用清单

1. 只报 p 值不报效应量与样本量（大样本下微小差异也显著）。
2. 多重比较未校正（假阳性膨胀）。
3. 用小样本 Shapiro-Wilk 的 p>0.05 当作正态性证明。
4. 把标准化系数与原始系数混着解读。
5. 数据驱动地反复换检验直到显著（p-hacking）。
